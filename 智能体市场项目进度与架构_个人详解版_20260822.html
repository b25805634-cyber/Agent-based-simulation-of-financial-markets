Project history

项目发展脉络：从叙事市场到行为蒸馏

V1｜Persona、新闻与社交传染

用散户、趋势、价值、量化、influencer、contrarian 等 persona 研究叙事如何进入订单与价格；历史报告提出过“社交条件性减震”“influencer 是 spark”等探索性发现。

V1 审计｜历史结论降级

真实 LLM 路径中正的 social_weight 只控制 feed 有无，数值强弱不进 prompt；fundamental 也未进入真实 prompt；旧市场允许不平衡双方全额 fill，隐含无限做市商。

Wave 0｜端点随机性

1,082/1,082 获得响应，1,081 成功解析；同 seed 两次原始输出不相同。结论：真实 Provider 不得声称严格确定。

Wave 1｜多事件验证未闭合

冻结 144 个运行，只有 53 个 honest-N，91 个失败或拒绝，完整 paired seed 数为 0；不能支持跨事件 confirmatory inference。

V2 prototype｜Teacher → Student → 守恒市场

去 persona、去新闻、去社交，改为 14 维量价与账户状态；Fake Teacher 480/480 跑通工程链，但 MLP 已输给 linear。

a1–a9｜真实 Teacher 失败链

经历响应形状、timeout、4K/16K/65K 截断、人工中断和连接异常；所有失败均保留且未拼接旧样本，下游正确 fail-closed。

a10｜第一次完整真实端点运行

162/162 Teacher、54 聚合状态、Student 训练、12/12 市场与 720/720 轮全部完成；工程 GO，蒸馏和科学解释 NO-GO。

为什么 V2 转向是对的

过去一句“你是散户”同时混入财富、风险偏好、信息来源、期限和情绪，结果变化时无法知道是哪项因素导致。V2 改为显式状态和可单独开关的机制，才有可证伪性。

方法论变化

从 identity-labelled generative agents 转向可版本化的条件政策 π(a,q|s)；从在线 LLM 市场转向离线监督蒸馏；从 reduced-form impact clearing 转向显式约束、集合竞价与资产负债守恒。

一轮市场怎么走

每天收盘时，所有人同时看同一段市场历史和各自账户，然后互相看不到订单地做决定。系统先检查钱和股票够不够，再统一撮合，最后一次性结算并生成下一天价格。

清算与守恒

候选价来自上一收盘与所有有效限价；依次最大化 matched volume、最小化 imbalance、最小化距上一价、固定较低价破最后平局。超额一侧按比例分配；总现金、股份、借款人债务与 facility loan asset 逐轮闭合。

这说明什么

模型确实会根据仓位和市场路径改变答案，例如上涨、现金较多时更可能买；下跌且持仓高时几乎都卖。但总体上它像一个“卖出机器”，买入样本太少。

为什么还不能叫稳定政策

K=3 让动作软标签只能取 0、1/3、2/3、1；buy 仅有 13 条、覆盖 6 个状态。没有 prompt counterbalancing、人类基准和冻结阈值，无法区分模型偏好、提示结构偏差与目标行为机制。

必须避免的表述：76.5% sell 不能解释为“真人悲观”“处置效应”或“MiniMax 普遍行为”； 它只是一条 endpoint-conditional empirical distribution。

为什么 accuracy 会骗人

Test 的 9 个状态里，8 个多数标签是 sell。Prior 不看状态、一直偏向 sell，也能得到 88.9% accuracy。看起来“最准”，却不代表学到了状态条件关系。

过拟合证据

MLP train CE 0.2439 几乎贴住训练软标签熵下限约 0.2427，但 validation/test 急剧恶化。应优先看 CE、Brier、calibration、per-class recall 与强度误差，而非总体 accuracy。

科学门：FAILED。不能把当前 MLP 称为“成功蒸馏的交易策略”；也不能事后改选 linear， 再继续使用已经看过的同一个 test 宣称成功。模型选择后必须建立全新的 confirmatory family set。

直觉

Student 的动作会改变价格和账户；新的价格和账户又成为它下一轮输入。只要第一轮略有偏差，后面就可能走进训练集从未覆盖的区域。

现有 OOD 只是 per-feature rectangular support diagnostic。超界不等于状态无效；当前尚未评估 joint support、manifold、density shift 或在这些状态上的行为正确性。

Distilled 两格

MLP 延续强 sell 倾向，买卖难以 crossing，平均 43–44 轮锁市。尚未跑 prior/linear 闭环，不能证明是 Teacher 特有状态依赖所致。

Finite momentum

三个 seed 从 −53.44% 到 +90.07%，均值 +10.59% 掩盖极高 between-seed variance，方向根本不稳定。

Credit momentum

信用零息、零费用、期内不还本，期末债务等于累计信用使用；三条路径都在最后一轮达到峰值，没有完整反转。

绝不能把 +140.26% 写成“收益”或“泡沫证据”。 系统没有独立 fundamental value；credit arm 是特殊的零成本购买力扩张；价格上涨没有扣除未偿债务， 也没有福利或可持续性含义。当前只能称为 3-seed exploratory simulator diagnostic。

Claim boundary

汇报时能说、不能说，以及下一道门

可以说

  • a10 在冻结请求和重试协议下获得完整 Teacher 数据。
  • Teacher 对当前状态设计表现出强烈卖出偏斜和有限状态反应。
  • 数据、训练、模型 lineage、市场和报告端到端运行。
  • 12 个市场、720 轮现金/股份/信用账本守恒。
  • 工程失败与负面模型结果都被保留，没有静默改成成功。

不能说

  • Teacher 代表真人、散户或普遍 LLM 行为。
  • 固定 MLP 已成功蒸馏 Teacher。
  • 已识别处置效应、后悔、注意力或预算独立因果效应。
  • 出现泡沫、盈利、社会福利或现实市场预测。
  • 3 seeds/cell 足以支持显著性和外推。
  • HiggsAI alias 独立确认了 MiniMax weights。

下一道门

  • Prompt multiverse 与高重复 Teacher qualification。
  • 同任务、激励相容的人类行为锚点。
  • 全新 confirmatory family 上胜过 prior 与 linear。
  • Teacher/Student/prior/linear 闭环等价与 OOD。
  • 有 fundamental、经功效设计的融资机制实验。

Strategic direction

整个项目未来方向：不是“更大的 LLM 市场”，而是可识别的实验金融平台

先识别人类或模型的条件交易政策，再研究它与预算、信息可见性、交易制度和公共传播如何共同形成市场动力学。
目标是可证伪、可复查、可重复的机制研究，不是价格预测器或实盘交易系统。

项目的真正“护城河”

  • Teacher → Student 的全链路 provenance 与失败可见性
  • 未见 family 与闭环 rollout 的双重验收
  • 显式账户、融资与清算守恒
  • 私人理由与公共传播的形式化隔离
  • 人类、LLM、Student 在同一可执行状态任务上的直接比较

Architecture implementation

架构实施建议：不重写，先把单体入口按职责机械拆开

第一优先级仍是 a10 备份。当前入口重构前，必须先建立至少两份内容寻址副本并完成恢复演练； 在此之前禁止 git clean -fdx、删除 worktree 或整理 nested clone。

为什么现在必须拆

experiments/v2_attention_market.py 已有约 4,850 行， 同时负责 profile、Provider、重试、Teacher、训练、市场、hash、manifest 和报告； 对应测试文件也有约 7,429 行。继续追加会让任何改动都像在改整个实验。

拆分原则

先做 characterization，再移动纯函数；旧 CLI 和 __all__ 保持兼容； 每次只拆一个职责，不同时改 prompt、Student、market、retry 或 schema。 源文件变化应升级 component fingerprint，绝不能冒充与 a10 身份相同。

最容易出错的迁移点

旧测试 monkeypatch 路径、JSON dict/float 序列化、repo root 推断、logical/physical计数、 raw-before-honest-N 顺序和 private SDK envelope 穿越模块边界。

第一轮重构的正确声明：“无科学机制变化；CLI/schema兼容；历史a10不变； source/component identity明确升级。”不要在重构分支上运行正式 endpoint 实验。

Roadmap

建议实施路线：每一步都有交付物与 Go / No-Go

00

封存证据与统一仓库

大白话：先把已经花钱跑出来的唯一数据保住。

专业任务：a10 public/private 分层不可变备份、恢复演练、全量 SHA-256；Teacher pilot 建 PR；明确唯一 canonical repo/worktree；只做 append-only post-run audit。

GO独立介质恢复后 hash 全一致。
NO-GO仍只有 ignored worktree 单副本。
01

冻结研究对象与声明矩阵

大白话：先说清楚到底要证明“模型怎么交易”，还是“人怎么交易”。

专业任务：estimand registry、E0–E5 claim ladder、V1/V2 分离的 ODD、calibration/validation/confirmatory 数据边界、每项机制的 null 与失败判据。

GO每条结论都能指向代码、配置、测试与数据。
NO-GO继续使用“更真实”这类不可证伪目标。
02A

独立 MarketCore 1.0

大白话：先造一个不用 LLM 也能被实验经济学检验的市场。

专业任务：constant/declining fundamental、dividend、terminal redemption、interest；uniform-price closed-book call；ZI、prior、fundamentalist、momentum、state-shuffled null；整数账本。

GO理论 null、账本与人类实验场景都可复现。
NO-GO价格仍依赖隐藏流动性或无对手方成交。
02B

建立人类证据库

大白话：先准备真人到底怎么选的参照答案，而不是让 LLM 自己证明自己像人。

专业任务：LtF、SSW 后继、ZTS 数据的版本/许可/hash；定义目标人群；冻结 54-state vignette、激励与伦理审批。

GO目标人群、任务映射和数据用途明确。
NO-GO把普通学生、散户与专业交易员混成一个总体。
03

Teacher 与 Prompt 资格

大白话：同一道题换个等价说法，答案不能大幅翻转。

专业任务：10–20 个关键 anchors × K20–30；平衡 6 种动作顺序、字段/enum 顺序、人称、单位、system/user 放置；多个 model families；所有失败保留。

GO状态效应明显大于 prompt-position 效应。
NO-GO结论依赖单一措辞或单一模型。
04

人类微型实验与行为锚定

大白话：让真人和模型做完全同一道题，比较的不只是平均答案，还包括人和人之间有多不一样。

专业任务：激励相容 choice、成对反事实、action distribution、variance、calibration、disposition/recency/reference-point treatment effects。

GO预注册分布与处理效应达到目标阈值。
NO-GO只能研究模型政策，不能称人类行为。
05

Student V2 与全新 confirmatory set

大白话：先让简单模型参加，再决定神经网络有没有必要。

专业任务：prior、regularized linear、GAM、小树、极小 MLP；soft targets；family-grouped validation；class balance；新冻结 test；CE/Brier/calibration/rare-action 指标。

GO新 family 上同时稳定胜 prior 与 linear。
NO-GO仍只在训练集拟合，或靠反复看 test 调参。
06

闭环等价与监督式补点

大白话：Student 自己行动后走到新地方，仍要做得像 Teacher。

专业任务：少量 Teacher rollout vs Student/prior/linear；equivalence margins；状态访问分布与机制统计；收集高频/OOD 状态重新标注，再以全新 rollout 验收。

GO单步与闭环指标同时等价。
NO-GO静态 test 好、闭环却持续漂移。
07

融资机制正式实验

大白话：把“多了钱”和“真的借了债”分开。

专业任务：finite cash、等额外生现金、zero-cost facility、有息且可偿还的 credit；合格政策 × matched controls；common random numbers、DiD、simulation-based power。

GO足够 seeds、预注册区间、机制方向稳定。
NO-GO继续用 3 seeds 和零成本债务做信用因果结论。
08

有限注意力与信息负荷

大白话：先研究给不给相关信息、有没有干扰信息，而不是靠多写几段文字假装“注意力不同”。

专业任务：relevant、masked、equal-length irrelevant、multi-message distraction；单资产称 information visibility，多资产后再研究 attention selection。

GO通道效应超过等长度 sham。
NO-GO处理同时改变信息量、格式与显著性却不拆分。
09

公共传播、同质化与外部验证

大白话：最后才让 Agent 互相影响，并证明不是“多问一次模型”自己造成的漂移。

专业任务：no-feed、same-call no-social、sham/permuted/frozen public feed、independent-before-social、topology/model heterogeneity；人类市场、第二 Teacher、stylized facts 与 post-cutoff 数据。

GO社会效应超过全部调用与信息量对照。
NO-GO从同向交易或高价格直接推断群体智慧/合谋。

Publication plan

建议论文规划：先行为基准，再闭环融资，最后注意力与社交

PAPER 0 · 方法/负结果

Auditable Acquisition and Closed-Loop Deployment of LLM Trading Policies

现有基础：provenance、honest-N、技术重试、private/public 边界、不可覆盖运行、整数账本，以及“完整数据但固定 MLP 输基线”的负结果。

不声称：人类行为、注意力、泡沫或因果市场效应。

PAPER 1 · 第一优先级

Human-Calibrated Conditional Trading Policies

核心问题：相同量价/账户状态下，真人、多个 LLM 与 Student 的动作分布、反事实方向、方差和校准是否一致？

最小证据：激励相容人类样本、prompt multiverse、多模型、独立 family/OOD。

PAPER 2 · 市场机制

Behavioral Policies and Financing Constraints in Conserving Markets

核心问题：经人类验证的条件政策，与 finite、额外现金、零成本 facility、真实 credit 如何交互？

最小证据：fundamental、ZI/prior/linear/human-policy controls、足够 seeds、闭环补点。

PAPER 3 · 信息与社会

Limited Attention and Public Communication in Agent Markets

核心问题：相关/无关信息、公共 feed、网络结构和模型同质性如何改变微观选择与群体动力学？

最小证据：equal-length controls、same-call no-social、sham/permuted feed、independent-before-social。

合谋建议另立第四篇。必须另建重复定价/竞价环境，预注册竞争价格、消费者福利、 punishment path 与 communication treatment；不能在资产价格共同上涨时顺带声称 collusion。

核心论文地图：每篇到底教会我们什么

Smith, Suchanek & Williams, 1988同行评审 · Econometrica大家都知道资产值多少钱，真人市场仍可能先涨后崩。提供实验 bubble/crash 基准；当前 V2 无 fundamental，不能套用 bubble 标签。
Gode & Sunder, 1993同行评审 · JPE市场有秩序，未必因为交易者聪明，也可能是规则约束得好。要求 ZI/null control；原文是私人价值 double auction，不等于当前 call market。
Plott & Pogorelskiy, 2017同行评审 · AEJ Micro集合竞价有严肃的价格发现基础，不是简化玩具。支持单价 call market；原实验的公开订单流、频率与真人制度不同。
Caginalp, Porter & Smith, 1998同行评审 · PNAS市场里初始现金相对股票多，价格往往更高。为 cash/asset ratio 和购买力处理提供直接依据；不验证 LLM 行为。
Capital Constraints and Asset Bubbles同行评审 · JEBO放松信用约束会让实验泡沫更大。支持融资处理；当前零息、不还本 facility 只能称购买力放松。
Odean, 1998同行评审 · Journal of Finance真实投资者更愿卖掉赚钱仓、抱住亏钱仓。支持成本价与浮盈亏特征；特征进入 prompt 不等于 LLM 已复现处置效应。
Barber & Odean, 2008同行评审 · RFS散户更容易买到那些最能吸引注意力的股票。完整机制需要多资产选择集；单资产只能研究信息可见性与 distraction。
Hashimoto et al., 2026 · FCLAgent同行评审 · JCSSLLM 决定买卖方向、规则决定价量，已经能接入 1,000-agent 订单簿。最近竞争者；说明“LLM + 规则市场 + 大规模 agent”已不是创新。
Henning et al. · LLM Agents Do Not Replicate Human Traders预印本LLM 市场往往比真人更理性、更整齐，泡沫更弱。警告不能把 LLM-only 市场当人类市场；需要同任务人类对照。
Machine Spirits, 2026预印本15 个模型表现不同，混合市场即使配置相同也可能走出完全不同路径。多模型与重复市场已被覆盖；项目应聚焦蒸馏、闭环与机制识别。
Gao et al., 2025同行评审 · PNAS大量重复问 LLM，仍不能可靠得到真人行为分布。直接否定“模型重复输出 = 独立人类样本”；要求人类锚定。
Bisbee et al., 2024同行评审 · Political Analysis平均答案可以像真人，但方差和条件关系可能完全不对。要求比较完整分布、协方差与时间/prompt 稳定性，不只看均值。
Questioning Survey Responses, 2024同行评审 · NeurIPS Oral选项摆前面还是后面、叫 A 还是 B，都会改变模型回答。支持平衡 action/enum/字段顺序的 prompt multiverse。
Do LLMs Play Dice?, 2025同行评审 · COLING模型能描述概率，不代表它能按那个概率稳定抽样。Provider randomness 不能自动解释为校准的人口异质性。
Hinton, Vinyals & Dean, 2015Workshop / preprint大模型的软输出可以压缩给小模型。支持 soft targets；不证明 Teacher 正确，也不证明 Student 闭环有效。
Ross, Gordon & Bagnell, 2011同行评审 · AISTATSStudent 自己行动后会走到训练集没见过的地方，错误越滚越大。解释 closed-loop covariate shift；支持 rollout 补点与独立复验。
Lorenz et al., 2011同行评审 · PNAS大家互相看答案会更一致，但不一定更准确。社会处理必须报告多样性，并设置 independent/no-social/sham controls。
Chuang et al., 2024同行评审 · Findings NAACL就算不互动，反复问模型也可能自己漂移；prompt 又能制造看似经典的碎片化。要求 same-call-count、sham、permuted 和 frozen-message controls。
Algorithmic Collusion by LLMs完整论文为预印本定价代理可能自行形成高价协调，轻微 prompt 变化也会影响结果。合谋需独立竞争环境与福利基准；当前资产 call market不能顺带声称。
ODD Protocol 2020 / Pattern-Oriented Modeling同行评审 · JASSS / Science先把模型是什么说清；不能因为像一条价格曲线就相信它。要求目的、状态、调度、子模型和多尺度模式验证；代码全绿只是 verification。

任何新改动都必须回答的八个问题

#问题为什么
1它改变的是 scientific、model request 还是 execution 语义？决定哪个精确身份和 hash 必须变化。
2参数从 CLI 到最终结果的 effect path 在哪里？防止“配置存在但不起作用”。
3对应 null/control/ablation 是什么？没有对照就无法归因。
4private rationale 是否可能泄漏？私有推理永不进入 feed、Student 或市场。
5失败会不会被改写成 hold 或静默丢弃？必须保留失败与 honest-N。
6历史 run 是否保持不可覆盖？任何新实验都必须使用新 run identity。
7数值、会计和隐私测试在哪里？代码完成不以“能跑”为标准。
8这项结果最终允许说到哪一层证据？工程 verification 不能替代人类或外部 validation。
新同学第一条原则：先读 manifest 和原始结果，再读报告；代码、测试、manifest、raw result 是事实源，文档描述的是设计意图和历史解释。

把昂贵大模型行为压缩成便宜、可重复的数值模型。
Soft target
不只记多数答案，还记 buy/hold/sell 各自出现的比例。
Honest-N
真正合法获得、成功提交且可以进入分析的样本数。
Family split
相似题及其重复不能一部分进训练、一部分进测试。
Cross entropy
模型答错而且特别自信时会被重罚；概率模型的关键指标。
Brier score
预测概率与实际 one-hot/soft target 的平方距离。
Calibration
声称 70% 的选择，在同类情形中是否真约七成发生。
OOD
模型遇到训练时没覆盖的新状态或新状态组合。
Closed loop
Agent 改变市场，市场又成为 Agent 下一轮输入。
Covariate shift
模型上线后遇到的输入分布和训练时不同。
Null / control
用于判断现象是不是市场规则或总体动作比例自己制造的对照。
Ablation
有计划地拿掉一个机制，看结果是否还存在。
Fundamental value
根据股息、利息和终值定义的资产经济价值；没有它不宜称泡沫。
Call auction
所有人先同时报单，再用一个统一价格一次撮合。
Difference-in-Differences
比较两个因素的交互，不是只看某格涨没涨。
Common random numbers
不同处理使用配对随机流，减少无关随机噪声。
Power analysis
实验前根据方差和目标效应算需要多少独立运行。
Internal validity
在模拟器内部，效果是否真的由指定处理造成。
External validity
结果能否推广到目标人群、其他模型或真实市场。
Provenance
每个结果究竟由哪份代码、配置、输入和请求产生。
