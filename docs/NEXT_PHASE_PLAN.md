## 0. 项目现状判读(大脑读档结论)

1. 社交传染 = 条件性减震器(2×2,d≈1.72,真新闻下 −45%→−26%)

4. 机制反转:阻尼来自同伴/价值/逆向的分布式广播链;influencer 是 panic spark(禁言/独麦/降级三臂消融,CI 全离 0)

## 1. 方法论转向(本阶段最重要的一个决定)

**放弃"确定性配对",全面转向"分布式推断":**

| 旧前提(已死) | 新框架 |
|---|---|
| temp=0 + 同 seed = 确定性配对 | 每个 (条件, seed) 跑 K 次重复,配对在**分布层面**做(配对均值差 + bootstrap CI / 随机化检验) |
| 逐字节复现科学结论 | Record/Replay 只用于**审计复现**(复播某个已观察 run);科学结论只看分布统计量 |
| 噪声靠工程消灭 | 噪声靠**先测噪底、再定 N、K**(功效分析前置) |

AGENTS.md 本来就写着 "Do not claim full determinism for real LLM providers" —— 这次只是把它升格为设计公理。

## 2. 三波路线(通往「涌现真实市场」)

### Wave 0 — 扫雷与地基(1–2 天,纯便宜,解锁一切)
- **T0.1 端点随机性定量**:同一 fixture prompt 重复 K=30 次 × (temp=0, temp=0.3),测输出不一致率、sentiment/order 方差;顺带验证端点是否认 `seed` 参数、串行 vs 并发是否影响方差。产出:**噪底 σ(temp) 表** → 重写所有功效计算(现有 σ_d=0.052 是 temp=0.3 人群级,需按新设计复核)。
- **T0.2 账务清理**:§11 结论标注作废/保留;results_2x2_v2 (12/60) 决议续跑或封存;15 条评审遗留项进 issue 跟踪。

### Wave 1 — 多事件验证(最高科学价值,正面回答"真实感")
- **已拍板的 3 个结局形态互异事件**:Meta 2022-02(崩而无弹,已有)+ **2020-03 COVID 崩盘 SPY(崩而 V 形反弹)** + **Meta 2023-02「效率年」财报 +20% 跳涨(利好不崩,同标的反号对照)**。
- **冻结单一配置**,用 `news_timeline` 让新闻逐轮演化(修 PROJECT 里"Meta 形态对不上"的已知问题:真实事件信息是逐日展开的,不是一次性 headline)。
- 网格:{事件 × 社交开/关} × N seeds × K repeats(K 由 T0.1 的 σ 定)。
- **判据 = 定性类别匹配**(崩/不崩、弹/不弹、相对深度排序)+ 风格化事实,**不是曲线拟合**。
- 通过标准预先写死(pre-registration 式),防 p-hacking——这正是 40-agent 评审教我们的。

### Wave 2 — 新统计体制下的机制问题
- **临界点扫描复活**:critsweep 重设计(阻尼盘占比 × hub 中心性,找减震→放大的相变线)。
- **Phase 2b 杠杆重跑**:K-repeat 设计替代确定性配对,钉死"杠杆放大多少"。
- **跨模型坐实**:HiggsAI 补到 N≥16。

### Wave 3 — 真实市场资格审查(Qualification Gate)
- **无目标自跑**:不喂参考序列,纯新闻流驱动,检验涌现价格序列的风格化事实是否落在真实市场区间(收益峰度、|r| ACF 慢衰减、涨跌不对称)。
- **人群扩展**:30 → 100 agent 成本/延迟压测(cheap model 分层:燃料盘用便宜模型、阻尼盘用强模型)。
- 产出一份「模拟市场真实性报告」,这是"最终产出真实市场"的验收单。
